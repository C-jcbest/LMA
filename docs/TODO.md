## 2026-11-09 交互检查发现（未修复）

以下由本轮代码检查或浏览器日志确认，尚未扩大到实现；主题、分隔线、宽度记忆和展开过渡已在本轮处理。

- [ ] 巡检后台失败或进程中断缺少明确反馈：`SessionStorage.latest_inspection()` 只返回进行中和最近成功结果，`TodayAttention` 的启动失败提示无法覆盖后台终态；需要返回并展示最近失败或中断状态，同时保留上一份成功结果。

- [ ] 巡检分组超过 6 个时分组筛选入口消失：当前只为少量分组绘制分段按钮，未提供多分组选单。
- [ ] 依据切换页签会卸载内容：从时间轴切到场地或明细再返回会重建图表，缩放范围和图例选择不保留。需要明确保留范围与生命周期，再决定保存视图状态还是保留挂载；不能为记住视图无限保留所有历史图表。
- [ ] GNSS 明细“显示全部”一次渲染全部返回行，且无法收起：数据量较大时 DOM 数随返回行数增长。应结合实际行数选择分页或虚拟列表，尚未做性能测量。
