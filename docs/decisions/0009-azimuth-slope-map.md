# 0009：位移方位与坡向、单点地图、回放与 3D 地形

- 日期：2026-11-13
- 状态：有效；3D 地形是否生效待真实环境验证

> 决策记录保存当时的背景与理由，是历史，不是现行规则的来源。现行架构见 [architecture.md](../architecture.md)；被取代的内容以后续记录为准。

- 位移方向是否与下坡方向一致，是区分坡体变形与观测墩/设备问题的关键事实。get_displacement 由系统计算水平位移方位（累计与本窗口，从正北顺时针）交给模型，不让模型自行换算角度；坡向仍来自 inspect_site_environment 的约 90 m 地形，代表周边平均坡面，提示词要求说明这一限制。是否比较由模型按问题决定，不新增固定步骤。
- 对话地图在单个测点时也显示；同组其他测点的位置随位移依据的 artifact 下发（`location.group_stations`），只作灰色参照，不进入模型上下文，也不当作本次取得的位移依据。
- 下坡方向以扇形画在测点下、位移箭头之上，弹窗给出夹角；位移回放复用依据中的累计水平位移轨迹（最多 240 个样本），以全程最大值定箭头比例。
- 3D 地形使用高德 `viewMode: '3D'` 与 `terrain` 选项，视图模式创建后不能切换，开关时重建地图；仍禁止旋转以保持正北朝上，倾斜后的箭头只是屏幕示意。`terrain` 在 2.0 下是否生效未经真实环境验证，见 TODO。
