# Langfuse Cloud 调查追踪

日期：2026-11-17。状态：已接受。

## 背景

需要按会话排查主调查中的模型调用、工具失败、耗时和用量。LMA 已使用 LangChain/LangGraph 官方 Agent，可复用 Langfuse 官方回调。

现有腾讯云主机约 2 核 2 GB 内存，检查时可用内存不足 1 GB；同时部署 Langfuse 应用与其存储组件不适合现有资源。用户检查资源后选择 Langfuse Cloud。

## 决定

- 采用 Langfuse Cloud，区域与项目地址显式配置；不在 LMA 主机新增追踪存储服务。追踪默认关闭，项目凭据仅保存在运行环境。
- 官方 CallbackHandler 采集模型、工具和用量，每轮独立创建；根观察关联业务 Run 和会话，并单独记录运行终态。
- 采用 SDK 后台批量导出，关闭服务时等待队列发送完成；不在每轮调查结束同步 flush。导出边界移除已配置的秘密值。
- 追踪是诊断副本，LangGraph checkpoint 继续作为会话历史事实来源。首批只覆盖主调查与内部摘要，独立标题、问题推荐和批量巡检不扩展到本次接入。

## 影响

无需额外自托管基础设施，增加 SDK 依赖及 Cloud 的网络与存储使用。启用后调查输入输出和工具数据会上传到所选 Cloud 项目，需由管理员配置凭据、核对模型定价与保留策略，并用真实调查确认接收。
