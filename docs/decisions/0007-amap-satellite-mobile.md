# 0007：地图聚焦卫星影像与移动端手势

- 日期：2026-11-13
- 状态：有效

> 决策记录保存当时的背景与理由，是历史，不是现行规则的来源。现行架构见 [architecture.md](../architecture.md)；被取代的内容以后续记录为准。

- 用户反馈手机地图不能滑动，原因为两张地图仅对精细指针启用拖动。统一开启平移与触屏缩放，地图区域接收触摸手势，区域外仍可滚动页面；关闭旋转，保证位移箭头与正北方向一致。
- 两张地图默认卫星图，可切换普通地图。用户确认区域地层和构造线叠加无助于当前调查，移除前端叠加层、开关、瓦片请求及专用依赖；已取得的场地环境文字资料仍可查阅。此决定替代上节对区域图层的展示约定。
- 站点类型来自既有测点资料。基准站保留位置与身份，不显示位移箭头或方向角；移动站沿用水平位移方向展示，箭头长度为相对示意。

### 2026-11-13 补充：纯卫星影像与测点信息

- 用户要求卫星图不默认出现道路线。调查地图和场地地图统一只显示卫星影像，RoadNet 的道路与地名注记由独立开关主动开启；普通地图保持高德原生道路与注记。切换底图不重建地图，也不重置用户选择。
- 两处地图共用测点标签与自定义信息卡：区分当前调查点、同组点和基准站；点击查看身份、状态、已有位移量与方向、坐标或安装位置。位移数值与单位分层显示，零水平变化不标注虚假的北向方位角，基准站不显示位移箭头或方向角。没有调查数据时不补造状态或数值。
- 地图的后续用途优先围绕坡体内的多点同期变化、位移方向与地形关系、圈选范围发起调查和现场复核准备；这些仍是候选方向，本次不增加新的分析工具或数据来源。
