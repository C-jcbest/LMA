额外流程复审修复：并发启动巡检用锁防止重复任务；复用原证据恢复图表与引用；失败查询有可查看的真实限制；报告之后的纠错/说明在页面和导出保留；同名站图表选择和范围问题包含 UUID；旧结论不冒充通过新契约验证的状态。最后复查补上整站“未见明显变化”必须有 N/E/U 三方向充分观测，单方向充分或共同样本不能替代整站目标窗口。

## 存量迁移与回退评审

发布沿用 `python -m app.server.storage` 与既有部署程序，构建后先 pg_dump，再迁移、启动并检查健康，最后切换 current。生产配置只在服务器读取。

- 新增 UUID 结果/记录表、revision、contract_version、execution_id 和恢复消息；旧表、快照和 checkpoint 全保留。不双写旧业务表，不新增旧接口回退。
- 历史关联优先保留已发布版本登记的 UUID；否则仅用原回答所在轮内的唯一身份映射，歧义或缺消息时不猜造。旧状态迁入标记 validated=false，界面显示历史结论而不当成新验证结果。
- 旧调查保留 previous_progress/previous_status，将目标标记待复核；旧 completed 暂停，不能继续沿用较弱旧契约的覆盖状态。证据执行身份只在唯一找到原模型消息时迁移；未能确定的原快照保留。
- 当前生产盘点未见有歧义的历史 UUID 关联；部署后仍核对数量和健康。DDL 不删除历史。旧代码可读取原表，但回退旧版本后不会展示新表新增的 UUID 结果；checkpoint 和证据仍在。需要人工判断目标版本契约，不能为恢复旧界面直接还原数据库。
- 代码回退用文档中的既有 Compose 与历史已核验 SHA；不 down -v、不清卷、不自动恢复数据库。备份保留在 `/opt/lma/shared/backups/`。

## 真实模型结果与限制

原始记录保存在 Git 忽略目录 `backend/evaluations/results/`，不包含真实监测数据。`model-evaluation-final.json` 为 14 场景全套；`model-evaluation-events-corrected.json` 为事件场景修正后的独立复跑；`model-evaluation-contract-review.json` 是确定性引用复核。保留此前失败记录，没有只保存成功轮次。

| 场景 | 实际观察 |
| --- | --- |
| 新站末端跳变 | 查近期与长期并补取跳后数据，识别末点 100mm 且保持未知；仍需专业审阅其共性基准问题推断强度。 |
| 共同样本 | 原站数量与共同样本在结构化事实中分开，数量程序复核无误；自然语言仍可能过度肯定缺测不影响判断。 |
| 历史刷新 | 复用原窗，另取当前序列，区分原结论与新增台阶，保留未调查 B。 |
| 续查 | 只向剩余 B 发起两次取数，不重新查询 A；原窗完成。正式报告经过三次类型/范围纠错；不能据此说调用效率最优。 |
| 台账边界 | 自然回答拒绝仅凭列表判断加速，没有无意义取数。 |
| 采样质量 | 正确识别 13 个预期时刻、方向不同有效量、重复与边界缺测；正文把三向取样都称为四点不够精确，不能记为自然语言事实全部通过。 |
| 多事件 | 首次模型无有效回答，运行层已拒绝假成功；修正后复跑给出 +10/-4mm 两事件、各自保持和 48 小时未知，仍建议专业审核成因推断。 |
| 日周期/弱趋势 | 自主分窗并增加每日同刻，区分周期与趋势；合成零噪声/周期不能证明真实噪声下判定可靠。 |
| 参考缺失 | N 固定累计与 H/D 未知，N 窗口净变化仍可算，没有用窗口首点替代参考。 |
| 同名站 | 两 UUID 分开，跨组没有伪造同组；报告窗口校验多次纠错后交付，记录原轨迹。 |
| 天气/场地 | 简单解释不强制建调查，不以预报/当前快照证明历史降雨因果；本场景未真实调用天气/场地。 |
| 部分失败 | A 成功保留，B 超时明确无法分析，成功提交不足结果；B 重复重试较多，后续应按实测请求成本优化。 |
| 并行目标 | 两目标正确记录且 completed；真实模型这次未触发 CAS 冲突，冲突保证来自隔离库并发回归。自由文本将 B 的缓变称未见明显变化并过强解释其地质意义，开放判断不能记为专业通过。 |
| 变更范围 | B 保留且 withdrawn、记录用户来源，A 独立分析后结束；撤回没有当作已回答。 |

当前必须修的身份、样本混用、存证恢复、状态并发和确定性计算缺陷已有代码与回归；合成评测不证明专业准确率。剩余须明确保留：真实监测噪声/初筛参数校准、真实基准变更与迁站资料、真实天气/场地端到端、长期模型稳定性、iPhone Safari 真机、异地备份和备份恢复演练。没有以增加正则、硬编码工具顺序或换模型掩盖开放推断问题。
