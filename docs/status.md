## 待验证（需要能访问对应服务的环境）

- [ ] 监测平台：用真实模型调查核对站点/分组解析、GNSS 时间窗和缺测、台阶候选、水平位移方位；测点页核对 7/30/90 天曲线、缺测标注和响应时间；确认模型会把 `focus_station` 当作未指明测点时的调查对象。本机访问平台登录接口曾被断开。
- [ ] 巡检初筛校准：在真实数据上运行一次，核对建议调查的比例和原因，按结果调整 [screening.py](../backend/app/inspection/screening.py) 中的噪声倍数，以及 [series_features.py](../backend/app/series_features.py) 中缺测前后位置差（5 倍中位数差不确定度）和速率逐段增大的判据。定时巡检和提醒在校准之后再决定。
- [ ] 调查耗时与调用上限：合成数据上“某点最近稳定吗”约 75 秒、5 次查询（思考开启）。在真实平台上按思考开/关各跑一组，比较总时长与结论质量，再决定 `LLM_THINKING` 默认值，并按实际调用分布校准 `AGENT_MODEL_RUN_LIMIT`（现 15）与 `AGENT_TOOL_RUN_LIMIT`（现 20）。
- [ ] 区域地质单元：在真实测点上看一次 Macrostrat 返回质量，没有用处时场地结果只保留地形。
- [ ] 天气：在可访问 Open-Meteo 的环境验收“某天几点下雨”和降雨前后对照；评测未绑定天气工具。
- [ ] 高德地图：在能连接高德的环境查看下坡方向扇形、单点地图的同组参照点、位移回放和 3D 地形。重点确认 `terrain` 在 JSAPI 2.0 下是否有地形起伏；若需要 2.1Beta，再评估升级加载版本的影响。
- [ ] 坡向精度：坡向来自约 90 m 地形；有勘查报告的主滑方向时对照一次，决定是否需要人工登记主滑方向。
- [ ] iPhone Safari 真机：软键盘、安全区、横竖屏、会话抽屉与焦点、地图手势、失败提示与重试。
- [ ] 历史会话编辑：在真实服务中复核已有会话的首轮与多轮编辑、重新生成和刷新后历史一致。
