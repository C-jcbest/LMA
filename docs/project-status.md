## 当前能力与交付边界

- FastAPI + LangGraph OSS + PostgreSQL，单 worker 自托管于腾讯云；main 推送后由 GitHub Actions 测试并部署，部署前备份数据库。不需要 Agent Server / LangSmith Deployment 许可证。
- 智能体工具：find_stations、get_displacement（累计偏移、窗口净变化、鲁棒趋势、台阶候选、缺测、水平位移方位，可分段或同组共同时段对比）、query_weather、inspect_site_environment（DEM 坡度坡向、区域地质）、compute（子进程沙箱）、record_conclusions、get_station_history。同一会话 10 分钟数据块缓存。
- 前端使用 assistant-ui 官方 Runtime：章节式正文内嵌依据卡片（可收起），测点依据面板含时间轴与明细；今日、测点、记录三个入口；推荐问题基于最近巡检与登记结论。
- 地图使用高德 JavaScript API 2.0（运行时 AMAP_TOKEN），WGS84 仅在展示时转 GCJ-02。
- 同一会话只允许一个 Run；部署重启会中断正在运行的调查。编辑和重新生成显示最新回答，暂不提供旧回答分支切换。
- DeepSeekThinkingChatModel 仍是现用适配，见 TODO。
