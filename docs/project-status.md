- 已迁移到 FastAPI + LangGraph OSS + PostgreSQL，单 worker 自托管；不需要 Agent Server / LangSmith Deployment 许可证。旧本机容器、数据库与会话保留，云端从独立新库开始。
- 前端使用 assistant-ui 官方 Runtime，历史由 checkpoint 管理。编辑和重新生成显示最新回答，旧 checkpoint 保留，暂不提供旧回答分支切换。
- 取消跨会话 Run 数量上限；同一会话仍只允许一个 Run，重复提交返回 409。数据库连接、内存、供应商配额和单轮调用预算仍有限。
- DeepSeekThinkingChatModel 仍是现用适配；上游原生支持思考内容回传且回归通过后删除，见 TODO。
